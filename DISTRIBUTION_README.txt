Sound Stitch 사용 안내
======================

1. 실행 방법
이 폴더 안의 "Sound Stitch.exe"를 더블클릭하세요.
EXE만 다른 위치로 옮기지 말고, 이 폴더 전체를 함께 보관하거나 복사하세요.

2. 기존 목록 복원
추가한 주소, 순서, 음량, 제목 설정은 프로그램을 껐다 켜도 자동으로 복원됩니다.
목록 데이터는 다음 위치에 저장됩니다.
  %APPDATA%\sound-stitch\data

프로그램을 새 버전으로 교체해도 위 데이터 폴더를 지우지 않으면 목록은 유지됩니다.

3. 완성 MP3 위치
완성된 MP3 파일은 다음 폴더에 저장됩니다.
  내 PC\음악\Sound Stitch

MP3 제작이 완료되면 저장 위치가 자동으로 열립니다. 이때 프로그램은 종료되지 않습니다.

4. 완성 영상 위치
완성된 MP4 파일은 다음 폴더에 저장됩니다.
  내 PC\동영상\Sound Stitch

영상 제작이 완료되면 저장 위치가 자동으로 열리고 프로그램이 종료됩니다.

5. 주요 기능
- YouTube 주소 여러 개 등록 및 순서 변경
- 영상별 음원 추출, 미리듣기, 음량 조절
- 약 3초 크로스페이드로 자연스럽게 연결한 MP3 제작
- 선택한 이미지와 합친 MP3로 MP4 영상 제작
- 곡 재생 구간에 맞춰 중앙에 제목 표시

6. 주의
- 본인이 소유하거나 다운로드 및 편집 권한을 가진 영상만 사용하세요.
- 연령 제한, 비공개, 지역 제한, 로그인이 필요한 영상은 가져오지 못할 수 있습니다.
- 프로그램 구성 파일이 들어 있는 resources 폴더를 삭제하지 마세요.
