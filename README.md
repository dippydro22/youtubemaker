# Sound Stitch

YouTube 영상의 음원을 차례로 준비하고, 미리듣기와 음량 조절을 거쳐 원하는 결과물로 만드는 로컬 프로그램입니다.

## 할 수 있는 일

- YouTube 영상 링크를 원하는 만큼 추가
- 영상별 MP3 미리듣기와 0~200% 음량 조절
- 영상별 중앙 제목 표시 여부와 문구 편집
- 위·아래 버튼으로 이어 붙일 순서 변경
- 각 음원을 개별 MP3로 담은 ZIP 생성
- 모든 음원을 순서대로 합친 256kbps MP3 생성
- 선택한 이미지와 합친 음원으로 1080p MP4 생성
- MP4에서 각 음원의 재생 구간에 맞춰 중앙 제목 자동 전환

## Windows 프로그램 실행

완성된 데스크톱 앱은 다음 파일을 더블클릭합니다.

`release\win-unpacked\Sound Stitch.exe`

브라우저나 검은 서버 창 없이 독립 프로그램 창으로 실행됩니다. `win-unpacked` 폴더 안의 다른 파일은 프로그램 구성요소이므로 EXE만 다른 위치로 옮기지 마세요. 필요하면 폴더 전체를 복사하면 됩니다.

## 브라우저 방식 실행

기존 브라우저 방식이 필요하면 `start.bat`을 더블클릭합니다. 검은 실행 창은 프로그램 서버이므로 사용하는 동안 닫지 마세요. 종료할 때는 그 창에서 `Ctrl+C`를 누릅니다.

개발 명령은 다음과 같습니다.

```powershell
pnpm install
pnpm start
```

데스크톱 앱을 다시 빌드하려면 `pnpm dist`를 실행합니다.

브라우저 주소는 `http://127.0.0.1:4173`입니다. 결과 파일은 `data/outputs`에 보관됩니다.

## 참고

- 본인이 소유하거나 다운로드 및 편집 권한을 가진 영상만 사용하세요.
- 연령 제한, 비공개, 지역 제한, 로그인 필요 영상은 가져오지 못할 수 있습니다.
- 최초 음원 추출 시간은 영상 길이와 네트워크 속도에 따라 달라집니다.
